Data Overview:
The dataset consists of 4,526 samples, each containing 91 data points. Given the duration of data collection (180 seconds), this corresponds to approximately 25 samples per second.

Comparison Strategy:
The analysis involves various comparisons to understand the characteristics of the data under different conditions. These comparisons include:

1. Single Subject (Diagonal) vs. Empty vs. Multi-Subject (Diagonal)
2. Single Subject (Random) vs. Empty vs. Multi-Subject (Random)
3. Single Subject (Diagonal) vs. Empty vs. Multi-Subject (Random)
4. Single Subject (Random) vs. Empty vs. Multi-Subject (Diagonal)
5. Single Subject (Diagonal) vs. Empty vs. One Person Static, Other Moving
6. Multi-Subject (Diagonal) vs. Empty vs. One Person Static, Other Moving

Analytical Approach:
- Data Preprocessing: To simplify the analysis, the mean of the 91 data points in each sample was calculated, resulting in 4,526 samples each containing a single data point. This approach is analogous to using a 1-second window for data analysis.
- Signal Processing: Initial plots of amplitude and phase against the number of data points were unsatisfactory. To improve clarity, a moving average filter was applied, with a window size of 200 proving most effective. Additionally, a Butterworth low-pass filter (order=10, cutoff=0.2) enhanced the visual quality of the results.
- Data Segmentation: The data was segmented into 30-second intervals, each containing 750 samples (based on the sampling rate of ~25 samples/sec). A similar segmentation was performed for 10-second intervals for comparative purposes.
- Data Visualization: For plotting, the filtered data with a window size of 50 was utilized. 
- Observations: Segmenting the data into smaller samples did not significantly enhance visual differentiation but still highlighted differences between single and multi-subject scenarios.

Machine Learning Framework:
- Six distinct classes were identified for machine learning purposes.
- The dataset for each class comprises 4,526 samples, post-processing, where each sample contains 91 datapoints.
